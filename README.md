Wheelhouse Tattoo Co.
Mobile tattoo service platform connecting artists with clients for events, parties, and private bookings.
Features
Artist portal with profiles and booking management
Customer portal for browsing artists and booking appointments
Admin portal for platform management
Event-based booking system
Package and pricing management
Tech Stack
React / TypeScript frontend
Node.js API server
PostgreSQL database
Deployed on Replit
